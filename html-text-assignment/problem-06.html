My Programming Notes

JavaScript

JavaScript is a high-level programming language mainly used to make websites interactive and dynamic. It works with HTML and CSS to create modern web pages and applications. JavaScript can be used for handling user actions, creating animations, validating forms, and developing web applications. It is also used outside browsers for server-side development. Important Concept: JavaScript uses variables to store values that can be used and changed during the execution of a program.

Example: 

        let name = "Rudra";
        let age = 18;

        console.log("Hello World");
        console.log(name);
        console.log(age);

Java

Java is a high-level, object-oriented programming language used to develop desktop applications, Android applications, web applications, and large software systems. Java programs are compiled into bytecode that can run on different systems using the Java Virtual Machine. It is widely known for its reliability and portability. Important Concept: Java is an object-oriented programming language, which means programs can be designed using classes and objects.

Example: 

        public class Main {
            public static void main(String[] args) {
                String name = "Rudra";
                int age = 18;

                System.out.println("Hello World");
                System.out.println(name);
                System.out.println(age);
    }
}
